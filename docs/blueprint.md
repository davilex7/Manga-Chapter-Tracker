# **App Name**: Manga Chapter Tracker

## Core Features:

- Input File Processing: Accept a TXT file as input, where each line contains the name of a manga.
- Webpage Fetching: Fetch the HTML content of a specific website for each manga title.
- Chapter Extraction: Use an AI tool to extract the latest chapter number from the fetched HTML content. The tool will look for common chapter number patterns and identify the most recent one.
- Data Compilation: Compile the manga titles and their corresponding latest chapter numbers.
- Output File Generation: Save the compiled manga titles and latest chapter numbers into an output TXT file.

## Style Guidelines:

- Primary color: White or light gray for clean readability.
- Secondary color: Dark gray for text and important information.
- Accent: Teal (#008080) for highlighting the active manga or chapter.
- Clean and readable font for manga titles and chapter numbers.
- Simple, list-based layout for displaying manga titles and chapter numbers.
- Subtle loading animations when fetching data for each manga.

## Original User Request:
I want an app for the following purpose:
Given an input txt file with the name of a manga on each line, access a specific website, search for each manga in the list, and record the chapter of each manga in an output txt file.

Prepare the base and ask me for whatever you need, for example, images of the different steps to follow on the website to perform the search and check the episode count, or perhaps you'd prefer the HTML of the page instead of images, along with the website URL and anything else you need.
